# v1.10.0 发行说明

## 概述

v1.10.0 是一次重大功能与架构升级版本。本版本引入完整的 MCP（Model Context Protocol）服务器，让 AI 代理能够直接查询和管理 DNS 记录；新增平台无关的应用引导层和 SQLite 统一存储，实现 Tauri 桌面端与 MCP CLI 共享同一套数据；同时完成 Rust 2024 Edition 升级、TLS 后端切换为 rustls，并大幅强化 CI/CD 自动化流程。

## 新增功能

### 🤖 MCP 服务器（dns-orchestrator-mcp）

全新的 Model Context Protocol 服务器，为 AI 代理（如 Claude Code、Cursor 等）提供 DNS 管理能力：

**8 个 MCP 工具**：
- `list_accounts` — 列出所有配置的 DNS 提供商账户（Cloudflare、Aliyun、DNSPod、Huaweicloud）
- `list_domains` — 列出指定账户下的域名，支持分页
- `list_records` — 列出域名 DNS 记录，支持分页、类型过滤和关键词搜索
- `dns_lookup` — DNS 查询（A/AAAA/CNAME/MX/TXT/NS/SOA/SRV/CAA/PTR/ALL）
- `whois_lookup` — 查询域名 WHOIS 信息
- `ip_lookup` — IP 地理位置查询（国家、地区、城市、ISP、ASN）
- `dns_propagation_check` — 全球 13 个 DNS 服务器的记录传播检查
- `dnssec_check` — DNSSEC 部署验证（DNSKEY、DS、RRSIG）

**设计特点**：
- 只读模式：与桌面应用共享数据但不修改，确保数据安全
- 紧凑型响应：专为 LLM 令牌效率优化，去除冗余字段
- 信息泄露防护：内部错误脱敏处理，只在日志中记录细节
- 超时管理：各操作独立超时（DNS 查询 30s、传播检查 60s 等）
- 多路径存储检测：兼容新旧应用标识符的数据目录

### 🏗️ 应用引导层（dns-orchestrator-app）

新增平台无关的应用状态管理和存储适配器：

**核心组件**：
- `AppState` / `AppStateBuilder` — 服务容器与构建器模式
- `StartupHooks` — 平台特定启动回调（迁移、凭证备份/恢复）
- 完整的启动生命周期管理

**SQLite 统一存储**：
- 基于 SeaORM 的 SQLite 适配器，支持账户、域名元数据、凭证的完整 CRUD
- 内置数据库迁移系统
- 为 MCP/TUI/CLI 等非桌面端场景提供开箱即用的存储方案

**Keyring 凭证存储**：
- 基于系统 keyring 的凭证存储适配器
- 从 Tauri 模块提取为共享组件

### 🔍 强类型 DNS 查询枚举

工具箱引入 `DnsQueryType` 强类型枚举：
- 覆盖所有 DNS 记录类型（A/AAAA/CNAME/MX/TXT/NS/SOA/SRV/CAA/PTR/ALL）
- 实现 `Display`、`FromStr` trait
- 支持 `schemars` JSON Schema 生成
- 取代原有的字符串传参方式

### 🏠 首页近期访问清理

自动清理已失效的近期访问域名记录：
- 当账户或域名缓存变化时触发
- 仅在缓存完整加载后执行，避免误删

### 🔧 Homebrew 自动发布

新增 Homebrew Cask 和 Formula 自动更新流程：
- macOS 桌面应用的 Cask 自动更新（支持 Apple Silicon 和 Intel）
- MCP CLI 的 Formula 自动更新（多平台二进制）
- SHA256 校验和自动计算

## Bug 修复

### 🔒 错误信息泄露防护

- `InvalidCredentials` 错误不再显示原始 API 消息，防止敏感信息泄露
- 错误日志与用户显示分离：详细信息写日志，通用信息返回给调用方

### 🗄️ SQLite 适配器修复

- 修复序列化错误处理中的 panic 问题
- 修复跨平台路径兼容性
- 修复解密失败时的错误恢复逻辑
- 优化查询与事务处理

## 重大重构

### 📦 存储层架构升级

将 Tauri 内部的存储适配器提取为共享的 `dns-orchestrator-app` 模块：

**之前**：Tauri 直接实现并持有所有存储适配器
**现在**：`dns-orchestrator-app` 提供统一适配器，Tauri 和 MCP 共享使用

**核心改进**：
- SQLite 数据库（`data.db`）作为统一数据存储
- Tauri 桌面端和 MCP CLI 读取同一份数据
- 向后兼容系统 keyring 凭证存储

### 🔐 TLS 后端切换

默认 TLS 后端从 `native-tls` 切换为 `rustls`：
- 纯 Rust 实现，无系统依赖
- 跨平台编译更一致
- 仍支持 `native-tls` 作为可选 feature

### 🦀 Rust 2024 Edition 升级

- 全工作区升级至 Rust 2024 Edition
- 统一代码格式化配置（`rustfmt.toml`）
- 统一 Clippy lint 配置

### 📋 依赖版本管理

- 内部 crate 从工作区路径引用切换为版本引用，为 crates.io 发布做准备
- 统一所有内部依赖版本号

## 升级说明

从 v1.9.1 升级到 v1.10.0 需注意以下事项：

### 对开发者

1. **Rust Edition**：全工作区升级至 Rust 2024 Edition
2. **新增依赖**：`dns-orchestrator-app` 和 `dns-orchestrator-mcp` 两个新 crate
3. **TLS 默认值变更**：`dns-orchestrator-provider` 默认使用 `rustls`，如需 `native-tls` 请指定 feature
4. **内部依赖引用**：从路径引用切换为版本引用

### 对用户

1. **功能兼容**：所有现有功能保持不变
2. **数据兼容**：无需数据迁移
3. **新增能力**：安装 MCP Server 后可通过 AI 代理管理 DNS

## 已知问题

- MCP 服务器当前为只读模式，不支持通过 AI 代理修改 DNS 记录
- SQLite 适配器仅用于非桌面端场景，桌面端仍使用 Tauri 原生存储 + keyring
